# MC Launcher

## Как получить .exe (ничего ставить на свой ПК не нужно)
1. Создай бесплатный аккаунт на github.com и новый репозиторий (ветка main).
2. Загрузи туда ВСЕ файлы из этого архива (включая папку .github).
3. Открой вкладку Actions -> "Build installer" -> Run workflow.
4. Через 3-5 минут скачай результат из Artifacts:
   - MC-Launcher-Setup-1.0.0.exe  — установщик
   - MC-Launcher-Portable-1.0.0.exe — запускается просто по файлу, без установки

## Если Node.js уже есть
npm install
npm run dist     (готовые exe появятся в папке dist/)
npm start        (запуск без сборки, для проверки)

Java ставить не нужно: лаунчер сам скачает нужную при первом запуске игры.
